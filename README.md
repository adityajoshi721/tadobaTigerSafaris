# Tadoba Tiger Safari website

A responsive, static landing page for Tadoba safari planning, resort stays and meals.

## View locally

Open `index.html` in a browser, keeping `styles.css`, `script.js` and `assets/` beside it. The page also works from any static web host.

The enquiry form prepares a WhatsApp message for **+91 86682 00472**. Visitors must press **Send** in WhatsApp to complete the enquiry. The site does not store leads or take payments.

Guest photographs are the supplied trip images. `assets/tadoba-hero.jpg` is an AI-generated illustration for the hero and is labeled as such on the page. Google Fonts are optional; local fallback fonts are defined in CSS.

Trip prices, safari permits, stay availability and inclusions require final confirmation. Wildlife sightings are never guaranteed.

`Tadoba_Tiger_Safari_Website_Download.zip` contains the same website files for direct download.
